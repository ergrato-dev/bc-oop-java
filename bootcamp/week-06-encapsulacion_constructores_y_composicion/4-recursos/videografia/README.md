# Videografía — Semana 06

| Canal | Qué buscar |
|---|---|
| [Java (canal oficial)](https://www.youtube.com/@java) | Busca "JEP Café" y "flexible constructor bodies": el cambio de Java 25 en los constructores, contado por quienes lo diseñaron |
| [Coding with John](https://www.youtube.com/@CodingWithJohn) | Busca "access modifiers", "getters and setters" y "final keyword": vídeos cortos, con el código a la vista |
| [Píldoras Informáticas](https://www.youtube.com/@pildorasinformaticas) | En español. En su curso de Java, busca los vídeos de encapsulación, modificadores de acceso y sobrecarga de constructores |

Muchos vídeos de encapsulación terminan generando un *getter* y un *setter* para cada atributo. Cuando lo veas, pregúntate qué *setter* de esos se saltaría una regla del dominio, como el `setCopies` del ejercicio 01.
