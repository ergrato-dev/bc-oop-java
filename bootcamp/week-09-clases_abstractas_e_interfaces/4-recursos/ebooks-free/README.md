# Ebooks gratuitos — Semana 09

| Libro | Qué leer esta semana |
|---|---|
| [Introduction to Programming Using Java (David Eck), sección 5.5](https://math.hws.edu/javanotes/c5/s5.html) | El final de la sección, *Abstract Classes*: un padre del que no se crean objetos y que obliga a sus hijas a escribir un método |
| [Introduction to Programming Using Java (David Eck), sección 5.7](https://math.hws.edu/javanotes/c5/s7.html) | *Interfaces*: la sección entera, con los métodos `default` y las interfaces como tipos. Deja las *lambdas* para más adelante |
| [Think Java, 2.ª edición (Allen Downey y Chris Mayfield)](https://greenteapress.com/wp/think-java-2e/) | En el capítulo *Extending Classes*, fíjate en las clases que heredan de una clase de Java y escriben los métodos que esta deja abiertos. Gratis en PDF y en HTML |
