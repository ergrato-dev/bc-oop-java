# Webgrafía — Semana 04

| Recurso | Para qué |
|---|---|
| [Use Cases and Stories (Martin Fowler)](https://martinfowler.com/bliki/UseCasesAndStories.html) | Qué diferencia hay entre un caso de uso y una historia de usuario, y por qué no compiten |
| [System Use Cases: An Agile Introduction (Agile Modeling)](https://agilemodeling.com/artifacts/systemusecase.htm) | Plantilla de caso de uso con flujo principal y alternativos, con ejemplos completos |
| [User stories with examples (Atlassian)](https://www.atlassian.com/agile/project-management/user-stories) | Cómo escribir historias de usuario y sus criterios de aceptación |
| [Given When Then (Martin Fowler)](https://martinfowler.com/bliki/GivenWhenThen.html) | De dónde sale el formato Dado-Cuando-Entonces y cómo se relaciona con un test |
| [Gherkin Reference (Cucumber)](https://cucumber.io/docs/gherkin/reference/) | El lenguaje que formaliza Dado-Cuando-Entonces para ejecutarlo como test; solo para leer, no se usa en el bootcamp |
| [CRC Models (Agile Modeling)](https://agilemodeling.com/artifacts/crcmodel.htm) | Cómo se hacen y se recorren las tarjetas CRC, con un ejemplo paso a paso |
| [A Laboratory For Teaching Object-Oriented Thinking (Beck y Cunningham, 1989)](http://c2.com/doc/oopsla89/paper.html) | El artículo original de las tarjetas CRC: corto y todavía vigente |
| [Ubiquitous Language (Martin Fowler)](https://martinfowler.com/bliki/UbiquitousLanguage.html) | Por qué el código debe usar las mismas palabras que el cliente: el glosario del dominio |
| [Requisito no funcional (Wikipedia)](https://es.wikipedia.org/wiki/Requisito_no_funcional) | En español: tipos de requisitos no funcionales con ejemplos |
| [JUnit: Display Names](https://docs.junit.org/current/writing-tests/display-names.html) | `@DisplayName` y los nombres de los tests parametrizados |
| [AssertJ: documentación](https://assertj.github.io/doc/) | Busca *as()*: cómo añadir una descripción al mensaje de fallo de una aserción |
