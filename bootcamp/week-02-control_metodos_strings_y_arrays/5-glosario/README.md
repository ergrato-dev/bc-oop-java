# Glosario — Semana 02

| Término | Definición |
|---|---|
| **Acumulador** | Variable declarada antes de un bucle que se actualiza en cada vuelta: `total += q` |
| **Ámbito** | Zona del código donde existe una variable: el bloque `{ }` donde se declara |
| **Argumento** | Valor que pasas al llamar a un método: en `level(2, 8)`, `2` y `8` |
| **Array** | Secuencia de tamaño fijo de valores del mismo tipo, accesibles por índice: `int[] stock = {4, 0, 7}` |
| **`ArrayIndexOutOfBoundsException`** | Excepción al pedir una posición menor que 0 o mayor que `length - 1` |
| **Arrays paralelos** | Dos o más arrays del mismo tamaño en los que la posición `i` describe el mismo registro |
| **`break`** | Sale del bucle en curso |
| **Bucle infinito** | Bucle cuya condición nunca llega a ser `false` |
| **Búsqueda lineal** | Recorrer un array de principio a fin hasta encontrar un valor; si no está, se devuelve `-1` |
| **`char`** | Primitivo con un solo carácter, entre comillas simples: `'B'` |
| **Condición** | Expresión `boolean` que decide si se ejecuta un bloque o se repite un bucle |
| **`continue`** | Salta el resto de la vuelta actual y pasa a la siguiente |
| **Cortocircuito** | `&&` y `\|\|` no evalúan la parte derecha si la izquierda ya decide el resultado |
| **for-each** | `for (int q : stock)`: recorre los valores de un array sin índice |
| **Índice** | Posición de un elemento en un array o un `String`, empezando en 0 |
| **Inmutable** | Que no cambia después de creado. `String` lo es: sus métodos devuelven textos nuevos |
| **Método** | Bloque de código con nombre, parámetros y tipo de retorno |
| **`null`** | Valor de una referencia que no apunta a ningún objeto |
| **Parámetro** | Variable de un método que recibe una copia del argumento |
| **Paso por valor** | Java copia el valor del argumento en el parámetro; para una referencia, copia la flecha |
| **`return`** | Devuelve un valor y termina el método |
| **Sobrecarga** | Varios métodos con el mismo nombre y distintos parámetros |
| **`StringBuilder`** | Texto que sí cambia; para construir `String` en bucles con `append` |
| **`switch` expresión** | `switch` con `->` que devuelve un valor y debe cubrir todos los casos |
| **Ternario** | `condición ? a : b`: elige entre dos valores dentro de una expresión |
| **Valor por defecto** | Lo que contiene un array recién creado con `new`: `0`, `false` o `null` |
| **`void`** | Tipo de retorno de un método que no devuelve nada |
| **`yield`** | Devuelve el valor de un caso de `switch` escrito como bloque `{ }` |
