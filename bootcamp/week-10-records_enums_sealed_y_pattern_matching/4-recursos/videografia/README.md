# Videografía — Semana 10

| Canal | Qué buscar |
|---|---|
| [Coding with John](https://www.youtube.com/@CodingWithJohn) | Busca "records", "enums" y "sealed classes": vídeos cortos, con el código a la vista |
| [Píldoras Informáticas](https://www.youtube.com/@pildorasinformaticas) | En español. En su curso de Java, busca los vídeos de tipos enumerados |
| [Java (canal oficial)](https://www.youtube.com/@java) | Busca "pattern matching", "record patterns" y "data-oriented programming": cómo encajan records, `sealed` y `switch` |

Algunos vídeos son de versiones de Java anteriores a la 21 y escriben `default` en cada `switch` o usan una cadena de `instanceof`. Cuando lo veas, pregúntate si un tipo sellado haría innecesario ese `default`.
