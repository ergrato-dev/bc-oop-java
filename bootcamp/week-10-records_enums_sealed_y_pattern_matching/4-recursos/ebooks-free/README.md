# Ebooks gratuitos — Semana 10

| Libro | Qué leer esta semana |
|---|---|
| [Introduction to Programming Using Java (David Eck), sección 2.3](https://math.hws.edu/javanotes/c2/s3.html) | El último apartado, *Introduction to Enums*: un enum sencillo, sin datos, y cómo usarlo en un `switch` |
| [Introduction to Programming Using Java (David Eck), sección 7.4](https://math.hws.edu/javanotes/c7/s4.html) | *Records*: la sección entera, con el constructor canónico (el que recibe todos los componentes) y los métodos propios de un record |

Ninguno de los dos cubre todavía los tipos sellados ni el *pattern matching* en `switch`: para eso usa la guía de Java 25 de la [webgrafía](../webgrafia/README.md).
