# Webgrafía — Semana 10

| Recurso | Para qué |

| [Using Record to Model Immutable Data (dev.java)](https://dev.java/learn/records/) | El tutorial oficial de los records: lo que Java escribe por ti, el constructor compacto y por qué un record no cambia |

| [Sealed Classes and Interfaces (guía de Java 25)](https://docs.oracle.com/en/java/javase/25/language/sealed-classes-and-interfaces.html) | `sealed`, `permits` y los tres modificadores de las hijas: `final`, `sealed` y `non-sealed` |
| [Pattern Matching for switch (guía de Java 25)](https://docs.oracle.com/en/java/javase/25/language/pattern-matching-switch.html) | Patrones en los `case`, exhaustividad con tipos sellados, `when` y casos dominados |
| [Record Patterns (guía de Java 25)](https://docs.oracle.com/en/java/javase/25/language/record-patterns.html) | Desmontar un record en `instanceof` y en `switch`, también records dentro de records |
| [JEP 456: Unnamed Variables & Patterns](https://openjdk.org/jeps/456) | Para curiosos: por qué existe `_` y dónde se puede usar. Los JEP son las propuestas con las que cambia el lenguaje |
