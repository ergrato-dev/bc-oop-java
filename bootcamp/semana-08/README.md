# 📚 Semana 8 – Colecciones y Programación Genérica

![Bootcamp Header](../../assets/bootcamp-header.svg)

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, serás capaz de:

- ✅ Diferenciar entre arrays y colecciones en Java
- ✅ Utilizar las interfaces principales de la API de Colecciones (List, Set, Map)
- ✅ Implementar iteradores y bucles mejorados (for-each)
- ✅ Aplicar programación genérica con tipos parametrizados
- ✅ Seleccionar la estructura de datos adecuada según el caso de uso
- ✅ Crear aplicaciones prácticas usando colecciones (inventarios, agendas)

---

## 📋 Contenido de la Semana

### 📖 Teoría
1. **Arrays vs Colecciones** - Diferencias y cuándo usar cada uno
2. **Framework Collections** - Arquitectura y interfaces principales
3. **List Interface** - ArrayList, LinkedList y casos de uso
4. **Set Interface** - HashSet, TreeSet y eliminación de duplicados
5. **Map Interface** - HashMap, TreeMap y estructuras clave-valor
6. **Iteradores y Bucles** - Recorrido eficiente de colecciones
7. **Generics Básicos** - Tipos parametrizados y type safety

### 💻 Práctica
1. **Ejercicio 1**: Sistema de Inventario con ArrayList
2. **Ejercicio 2**: Agenda de Contactos con HashMap
3. **Ejercicio 3**: Gestión de Productos Únicos con Set
4. **Ejercicio 4**: Biblioteca con Colecciones Múltiples
5. **Taller Integrador**: Sistema de Gestión de Estudiantes

### 📚 Recursos
- Glosario de términos de colecciones
- Referencias de la API de Java Collections
- Videos tutoriales recomendados
- Comparativa de rendimiento entre colecciones

## 🚀 Cómo Empezar

1. **Lee la teoría** en orden secuencial (01 a 07)
2. **Revisa los assets visuales** para entender la jerarquía de colecciones
3. **Realiza los ejercicios prácticos** comenzando por el más simple
4. **Consulta el glosario** cuando encuentres términos nuevos
5. **Completa el taller integrador** aplicando todos los conceptos

## 💡 Consejos para esta Semana

- 🎯 **Enfócate en entender cuándo usar cada colección** (no solo cómo)
- 🔄 **Practica con diferentes tipos de datos** en tus colecciones
- 📝 **Escribe código type-safe** usando generics desde el inicio
- 🧪 **Experimenta con diferentes implementaciones** (ArrayList vs LinkedList)
- 🤝 **Trabaja en pareja** para comparar soluciones y aprender
