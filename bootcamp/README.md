# Bootcamp POO con Java — Índice de semanas

24 semanas · 14 h/semana · 336 horas. Autoestudio asincrónico, 100% práctico, con un solo proyecto, el [sistema de gestión de tu dominio](../docs/proyecto-hilo-conductor.md), que crece cada semana.

Las semanas se publican por bloques al estándar de [`CLAUDE.md`](../CLAUDE.md): las publicadas enlazan al README de su semana desde el número y desde el tema.
