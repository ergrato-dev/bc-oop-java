## 🏆 Evaluación Final

### Distribución de Calificación

| Componente | Peso | Descripción |
|------------|------|-------------|
| Conocimiento | 30% | Cuestionarios, exámenes, presentaciones |
| Desempeño | 40% | Ejercicios, talleres, código POO |
| Producto | 30% | Proyecto final funcional |

### Criterios de Aprobación

- **Mínimo para aprobar**: 3.5/5.0
- **Requisitos obligatorios proyecto final**:
  - 5+ clases de dominio
  - 1 jerarquía (1 padre + 2 hijas)
  - 1 clase abstracta O 1 interface
  - ArrayList + HashMap
  - 2+ excepciones personalizadas
  - CRUD completo
  - README + UML
  - Presentación oral 10-15 min
