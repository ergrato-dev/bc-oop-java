# Videografía — Semana 07

| Canal | Qué buscar |
|---|---|
| [Coding with John](https://www.youtube.com/@CodingWithJohn) | Busca "inheritance", "super keyword" y "method overriding": vídeos cortos, con el código a la vista |
| [Píldoras Informáticas](https://www.youtube.com/@pildorasinformaticas) | En español. En su curso de Java, busca los vídeos de herencia, `super`, sobrescritura y `final` |
| [Java (canal oficial)](https://www.youtube.com/@java) | Busca "JEP Café" y "flexible constructor bodies": el cambio de Java 25 que te deja comprobar antes de `super(...)` |

Mientras ves un vídeo, para y predice qué imprime el código antes de que lo ejecuten: es lo que te pedirán en la sustentación.
